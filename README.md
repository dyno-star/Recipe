# 🍳 Recipe-AI: AI-Powered Recipe Generator

> “Don’t know what to cook? Let AI figure it out.”

**Recipe-AI** is a smart recipe generator powered by OpenAI. Just enter the ingredients you have, and it returns creative, AI-generated recipe ideas in seconds — helping reduce food waste and bring variety to your meals.

---

## 🤖 What It Does

- 🧠 Generates full recipes from a list of ingredients  
- 📝 Provides step-by-step cooking instructions  
- 🌱 Suggests recipes based on dietary preferences (e.g., vegetarian, low-carb, etc.)  
- 🔄 Outputs multiple ideas for each input  
- ⚡ Fast and lightweight — runs right from the command line
